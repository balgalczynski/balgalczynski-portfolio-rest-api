# Umbrella NMS REST API

A domain-driven REST API specification for the modernized Umbrella Network Management System. The OpenAPI definition models alarm ingestion, enrichment, correlation, and system‑level operations based on the architecture and domain concepts described in the Umbrella NMS modernization [case study](https://github.com/balgalczynski/balgalczynski-portfolio/tree/main/case-study).

## Features
- OpenAPI 3.1 specification for the Umbrella NMS.  
- Alarm management, correlation logic, and domain entities represented in YAML.  
- Swagger UI for interactive exploration.  
- Modular structure aligned with microservices architecture.  

## Repository Structure
- `openapi.yaml` - main REST API definition.  
- `index.html` - Swagger UI integration.  
- `/img` - diagram including the domain model.  
- `/css`, `/js` - Swagger UI assets.
